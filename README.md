# 업비트 자동매매 봇

매수/매도 조건을 화면에서 골라 조합하는 업비트(KRW 마켓) 자동매매 프로그램.

| 파일 | 역할 |
|---|---|
| `trader_app.py` | 설정 + 실행 + 현황 + 백테스트 화면 (Streamlit) |
| `run_bot.py` | 화면 없이 봇만 실행 (서버에서 24시간 돌릴 때) |
| `autotrader/` | API 클라이언트, 지표, 조건, 매매 엔진, 백테스트 |
| `bot.py` | 기존 차트 앱 (그대로 유지) |

## 실행

```bash
pip install -r requirements.txt
streamlit run trader_app.py
```

1. **모의투자**로 먼저 돌려보기 (기본값). 실제 주문 없이 현재가로 체결됐다고 가정하고 수수료 0.05%를 반영함.
2. 탭에서 조건을 고르고 **[설정 저장]** → `bot_config.json` 에 저장됨.
3. **[▶ 봇 시작]**. 실행 중에 저장하면 바로 반영됨 (모드 변경만 재시작 필요).

## 선택할 수 있는 조건

**종목 필터** (현재가 API 기준, 전일대비 = 매일 09:00 KST 기준)
- 24시간 거래대금 / 상승률 / 하락률 순위 N위 이내
- 전일대비 등락률 범위, 현재가 범위, 24시간 최소 거래대금
- 투자유의·투자주의 종목 제외, 특정 종목만 / 특정 종목 제외

**지표 조건** (매수·매도 양쪽에서 선택 가능, AND/OR 결합, 파라미터 조정 가능, 캔들 1분~월봉)
- RSI: 이하 / 이상 / 상향 돌파 / 하향 돌파
- 볼린저밴드: 하단 터치, 하단 재진입, 상단 터치, 상단 돌파, 중심선 돌파/이탈, %B 범위, 밴드폭 수축
- 이동평균(SMA/EMA): 골든/데드크로스, 가격 위/아래, 이평선 돌파/이탈, 정배열/역배열, 기울기, 이격도
- MACD: 골든/데드크로스(0선 위/아래 옵션), 0선 위, 히스토그램 증가
- 스토캐스틱: 골든/데드크로스(과매도/과매수 구간), %K 이하/이상
- CCI, Williams %R, MFI, ADX(+DI/-DI 방향), OBV, ATR%
- 거래량: 평균 대비 급증, 연속 증가, 봉 거래대금
- 가격/돌파: 변동성 돌파(K값), N봉 신고가 돌파, N봉 신저가 이탈, 고점 대비 X% 하락(눌림목), 저점 대비 X% 상승, N봉 전 대비 변동률 범위
- 캔들: 양봉/음봉 크기, 연속 하락 후 반등, N연속 양봉/음봉, 망치형

**매도 전용**: 익절 %, 손절 %, 트레일링 스탑, 최대 보유 시간, 매일 정해진 시각 청산, "지표 매도는 X% 이상 수익일 때만"

**자금 관리**: 1회 매수 금액(고정/가용 원화 %), 최대 보유 종목 수, 재매수 대기 시간, 하루 최대 매수 횟수, 하루 손실 한도, 남겨둘 원화, 매수 허용 시간대

## 실전 매매 전에 꼭 확인할 것

- **API 키**: 업비트 > 마이페이지 > Open API 관리에서 발급. 권한은 *자산조회, 주문조회, 주문하기*. 출금 권한은 절대 주지 말 것.
- **허용 IP**: 업비트는 키 발급 시 허용 IP를 등록해야 주문이 됨. 그래서 IP가 고정되지 않는 **Streamlit Community Cloud 에서는 실전 주문이 안 된다.** 집 PC(고정 IP) 또는 VPS에서 실행해야 함.
- **키 전달 방법** (설정 파일/깃에는 저장하지 않음):
  ```bash
  export UPBIT_ACCESS_KEY=...
  export UPBIT_SECRET_KEY=...
  ```
  또는 `.streamlit/secrets.toml`:
  ```toml
  UPBIT_ACCESS_KEY = "..."
  UPBIT_SECRET_KEY = "..."
  ```
- 봇은 **자기가 산 수량만** 판다. 원래 갖고 있던 코인은 건드리지 않음.
- 주문은 전부 시장가 (매수: 금액 지정, 매도: 수량 지정). 최소 주문금액 5,000원.
- 화면(Streamlit)을 끄면 봇도 꺼진다. 계속 돌리려면 `run_bot.py` 를 사용:
  ```bash
  nohup python run_bot.py > bot.out 2>&1 &
  python run_bot.py --once   # 한 사이클만 돌려서 설정 점검
  ```
- 기록은 `bot_data/` 에 모드별로 저장 (`state_*.json` 보유 현황, `trades_*.csv` 거래 내역, `bot_*.log` 로그).

## 백테스트 한계

한 종목 과거 캔들에 매수/매도 조건을 적용해 보는 참고용. 종목 필터(순위·전일대비)는 과거 재현이 안 돼서 빠지고, 신호는 봉 마감 기준으로 체결했다고 가정함. 실전에서 "진행 중인 봉" 기준으로 판단하면 결과가 다를 수 있음.

> 투자 손실 책임은 본인에게 있음. 반드시 모의투자와 소액으로 충분히 검증한 뒤 사용할 것.
